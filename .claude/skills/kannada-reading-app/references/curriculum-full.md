## Lesson Template {#template}

Copy this template for every new letter lesson:

```
LESSON: [Letter] — [Sound]
============================================================

STEP 1 — HOOK
  Hero image: [image search query]
  Caption: "ನೀವು ಇದನ್ನು ಪ್ರತಿ ದಿನ ನೋಡುತ್ತೀರಿ! (You see this every day!)"

STEP 2 — REVEAL
  Highlight: [letter] in the sign
  Audio: "[letter sound] — [full word pronunciation]"
  Text: "ಈ ಅಕ್ಷರ ಗುರುತಿಸಿ (Spot this letter)"

STEP 3 — ISOLATE
  Display: [letter] at 96sp, centered
  Stroke animation: yes
  Audio: repeat letter sound ×3

STEP 4 — PATTERN CARDS
  Card A: [image 2] → [word 2] → highlight [letter]
  Card B: [image 3] → [word 3] → highlight [letter]
  Card C: [image 4] → [word 4] → highlight [letter]

STEP 5 — VOWEL FORMS (advanced mode only)
  [letter] + ಾ = [form]  ([sound])
  [letter] + ಿ = [form]  ([sound])
  [letter] + ೀ = [form]  ([sound])
  [letter] + ು = [form]  ([sound])
  [letter] + ೂ = [form]  ([sound])
  [letter] + ೆ = [form]  ([sound])
  [letter] + ೇ = [form]  ([sound])
  [letter] + ೊ = [form]  ([sound])

STEP 6 — QUIZ
  Q1 (tap): "ಈ ಅಕ್ಷರ ಯಾವುದು? (Which letter is this?)" → [letter grid]
  Q2 (image): "ಯಾವ ಚಿತ್ರದಲ್ಲಿ [letter] ಇದೆ? (Which sign has [letter]?)"
  Q3 (trace): "ಬೆರಳಿನಿಂದ ಬರೆಯಿರಿ (Trace with your finger)"

STEP 7 — BADGE
  Badge name: "[Letter] ನಾಯಕ ([Letter] Hero)"
  Next lesson teaser: "ಮುಂದೆ: [next letter]"
============================================================
```


## Phase 3 — Vowel Sign Patterns {#phase3}

Each vowel sign lesson teaches the *matra* (vowel diacritic) using ONE base
consonant they already know (ಕ is recommended as the anchor).

### Lesson 17 — ಾ (aa matra)

```
Teach: ಕ + ಾ = ಕಾ
Real-world word: ಕಾಲೇಜು (College board)
Pattern: Show ಕ → add ಾ → becomes ಕಾ
Color: ಕ in blue, ಾ in red
IMAGE SEARCH: "college board Kannada Karnataka"
```

### Lesson 18 — ಿ (i matra)

```
Teach: ಕ + ಿ = ಕಿ
Real-world word: ಕಿರಾಣಿ ಅಂಗಡಿ (General store sign)
IMAGE SEARCH: "kirana shop sign Karnataka Kannada"
```

### Lesson 19 — ೀ (ee matra)

```
Teach: ಕ + ೀ = ಕೀ
Real-world word: ಕೀಲ್ (Wheel / gear signs at mechanics)
IMAGE SEARCH: "mechanic shop sign Kannada Karnataka"
```

### Lesson 20 — ು (u matra)

```
Teach: ಕ + ು = ಕು
Real-world word: ಕುಮಾರ ಸ್ವಾಮಿ (road sign / temple)
IMAGE SEARCH: "Kumarswamy road sign Bengaluru Kannada"
```

### Lesson 21 — ೆ (e matra)

```
Teach: ಕ + ೆ = ಕೆ
Real-world word: ಕೆಎಫ್‌ಸಿ (KFC — circle back to lesson 1!)
IMAGE SEARCH: "KFC sign Karnataka Kannada"
NOTE: This is a great callback moment — learner sees KFC differently now.
```

### Lesson 22 — ೊ (o matra)

```
Teach: ಕ + ೊ = ಕೊ
Real-world word: ಕೊಡ ನಿಲ್ಲಿಸಿ (No parking signs — ಇಲ್ಲಿ ನಿಲ್ಲಿಸಬಾರದು)
IMAGE SEARCH: "no parking sign Kannada Bengaluru"
```
